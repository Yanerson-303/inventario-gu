# Inventarios GU 2.3 — Parche acumulativo

Se conservan las funciones de 2.2, el inventario, registro semanal, vista 3D, analíticas, copias, instalación PWA y descargas PC/móvil.

Novedades:
- Controles de panel: mostrar todas, minimizar todas y restablecer preferencias.
- Exportación CSV del consolidado desde el panel, compatible con hojas de cálculo.
- Aviso compacto de referencias con saldo cero o negativo, con acceso al consolidado.
- Distribución adaptable de controles y alertas para teléfonos.
- Actualización de caché PWA a 2.3 y regeneración de archivos HTML autónomos para PC y móvil.

Los archivos descargables son HTML, no ejecutables nativos. Instalar la PWA requiere HTTPS o localhost. Cada dispositivo conserva sus propios datos.
