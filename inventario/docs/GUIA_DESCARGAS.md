# Inventarios GU 2.2

Publica la carpeta `public/` completa en HTTPS. Desde **Descargar app** puedes descargar el mismo HTML autónomo con un nombre para PC o para móvil. Para iPhone se recomienda instalar la PWA desde Safari con Añadir a pantalla de inicio. Los datos se almacenan localmente y no se sincronizan automáticamente.

En Panel general, usa **Minimizar / Mostrar** en cada métrica; las preferencias se conservan en el navegador. En Registro semanal, la tabla permite desplazarse horizontal y verticalmente.
