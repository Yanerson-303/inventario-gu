# Inventarios GU 3.3

- Hover suave sobre las barras SVG (sin audio al mover el puntero); puntos de línea y sectores circulares resaltables con etiquetas de valores.
- Encabezados de métricas con el icono funcional para contraer o expandir (rojo al apuntar), tanto en escritorio como en móvil.
- Botón «i» junto al título para información extendida (amarillo al apuntar).
- Gráficos y tarjetas ajustados para aprovechar mejor el espacio sin ocultar información.
- Audio generado localmente por Web Audio únicamente al abrir información o contraer/expandir, con opción de silenciar en Configuración.
- Conserva datos, fórmulas, bodega, filtros, registro semanal, respaldos, exportaciones y descargas HTML autónomas.
- PWA precachea también motion.js; nuevas versiones PC y móvil generadas con CSS y JS incluidos.

**Nota:** No se reproducen sonidos automáticamente ni al pasar el cursor por las barras. La web debe abrirse en HTTPS o localhost para instalar la PWA y asegurar un uso offline más fiable.
