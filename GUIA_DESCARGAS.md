# Inventarios GU 2.2

Publica esta carpeta completa en HTTPS. Desde **Descargar app** puedes descargar versiones HTML autónomas para PC y móvil. Para iPhone se recomienda instalar la PWA desde Safari con Añadir a pantalla de inicio. Los datos se almacenan localmente y no se sincronizan automáticamente.

En Panel general, usa **Minimizar / Mostrar** en cada métrica; las preferencias se conservan en el navegador. En Registro semanal, la tabla permite desplazarse horizontal y verticalmente.
