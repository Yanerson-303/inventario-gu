# Almendra: descarga desde la web

- Publica la carpeta `almendra-inventario-web` completa en HTTPS, sin cambiar su estructura.
- En la web, pulsa **Descargar app** y selecciona **Descargar PC** o **Descargar móvil**.
- Los archivos descargados son HTML autónomos con CSS y JavaScript incorporados, no ejecutables nativos.
- El proyecto web que se edita conserva los archivos `index.html`, `styles.css`, `app.js`, `db.js`, `calc.js`, `charts.js`, `warehouse.js`, `install.js` y `sw.js` por separado.
- Para instalación PWA en PC/Android usa la opción de instalar del navegador; en iPhone, Safari → Compartir → Añadir a pantalla de inicio.
- En iPhone la apertura de archivos HTML locales y la persistencia de datos dependen del navegador y de cómo se abra el archivo. Para uso estable y offline se recomienda instalar la PWA desde HTTPS.
- Cada dispositivo guarda su propia información. Usa Copias y migración para trasladar datos entre dispositivos.
